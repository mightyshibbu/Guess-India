# Party Charades

A fun party game where players guess words displayed on a phone held to their forehead.

## Features

- Simple and intuitive interface
- Score tracking
- Random word generation
- Responsive design that works on different screen sizes

## Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Android Studio / Xcode (for emulator/simulator)
- A physical device or emulator for testing

### Installation

1. Clone this repository
2. Run `flutter pub get` to install dependencies
3. Connect a device or start an emulator
4. Run `flutter run` to start the app

## How to Play

1. One player holds the phone to their forehead
2. Other players give clues to help them guess the word
3. Tap "Got It!" for correct guesses or "Skip" to move to the next word
4. Each correct guess gives you 10 points
